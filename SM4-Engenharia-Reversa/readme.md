# SM4 - Engenharia Reversa

## 📖 Sobre
Projeto desenvolvido para discutir Engenharia Reversa assistida por Inteligência Artificial, analisando impactos do desenvolvimento assistido por IA na formação de engenheiros de software e os desafios éticos relacionados à originalidade e ao plágio digital.

## 🎯 Objetivo
- Explorar conceitos de Engenharia Reversa;
- Analisar desenvolvimento assistido por IA;
- Discutir pensamento crítico no uso de IA;
- Refletir sobre ética, originalidade e plágio digital.

## 🛠️ Ferramentas Utilizadas
- Inteligência Artificial
- Engenharia Reversa
- Desenvolvimento Assistido por IA

## 🖼️ Resultado
O projeto demonstrou a importância do pensamento crítico, análise lógica e formulação de requisitos no uso de ferramentas generativas, além de discutir limites éticos entre inspiração, aprendizado e cópia digital.
