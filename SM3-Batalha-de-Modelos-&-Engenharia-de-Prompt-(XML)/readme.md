# SM3 - Batalha de Modelos & Engenharia de Prompt (XML)

## 📚 Sobre o Projeto

Este projeto foi desenvolvido para a atividade **Batalha de Modelos & Engenharia de Prompt (XML)**, com o objetivo de comparar como diferentes modelos de Inteligência Artificial interpretam um mesmo prompt estruturado em XML.

A proposta foi analisar a fidelidade das respostas geradas pelas IAs, observando se cada modelo respeitou as tags, as cores, os requisitos técnicos e a estrutura solicitada.

## 🎯 Objetivos

- Avaliar a precisão técnica de diferentes LLMs.
- Comparar a fidelidade ao prompt XML.
- Identificar erros de sintaxe no HTML gerado.
- Analisar a criatividade e a organização do conteúdo.
- Comparar o consumo estimado de tokens.

## 🤖 Modelos Avaliados

- ChatGPT
- Gemini
- Claude
- DeepSeek
- Qwen
- Grok
- Maritaca

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- XML
- Engenharia de Prompt
- Inteligência Artificial

## 📄 Descrição da Atividade

Foi criado um prompt estruturado em XML para gerar uma página **HTML Single Page** com **CSS integrado**.  
Esse mesmo prompt foi testado em diferentes ferramentas de IA, permitindo comparar o nível de obediência de cada modelo às instruções fornecidas.

## 📊 Critérios de Avaliação

- Precisão estimada do resultado
- Precisão do HTML
- Criatividade no conteúdo
- Erros de sintaxe
- Quantidade estimada de tokens utilizados
- Compreensão da estrutura XML

## 🧠 Reflexão

A atividade mostrou que cada IA interpreta o mesmo prompt de forma diferente. Alguns modelos respeitaram melhor a estrutura XML e os requisitos técnicos, enquanto outros foram mais criativos, porém menos fiéis às instruções.

Com isso, foi possível perceber a importância de criar prompts claros, organizados e bem estruturados para obter melhores resultados em tarefas de desenvolvimento Front-end.

## ✅ Conclusão

O experimento demonstrou que a Engenharia de Prompt é essencial para orientar modelos de IA de forma mais precisa. A comparação entre os modelos ajudou a entender quais ferramentas são mais adequadas para prototipagem rápida e quais são melhores para códigos mais complexos.
