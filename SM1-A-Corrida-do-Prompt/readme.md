# SM1 - A Corrida do Prompt

## 📖 Sobre
Projeto desenvolvido para a atividade de Engenharia de Prompt utilizando IA generativa. O objetivo foi refinar prompts em até 5 tentativas para gerar uma imagem medieval cinematográfica com melhor qualidade visual e maior legibilidade.

## 🎯 Objetivo
- Aprender técnicas de Engenharia de Prompt;
- Refinar respostas geradas por IA;
- Melhorar detalhes visuais através de iterações;
- Analisar o impacto das alterações nos prompts.

## 🛠️ Ferramentas Utilizadas
- Qwen AI
- Inteligência Artificial Generativa
- Engenharia de Prompt

## 🖼️ Resultado
A versão final apresentou:
- Estilo medieval/barroco;
- Melhor composição visual;
- Elementos cinematográficos;
- Texto mais legível;
- Aparência mais profissional.
