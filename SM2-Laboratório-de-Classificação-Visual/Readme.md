SM1 - A Corrida do Prompt
📖 Sobre o Projeto

Este projeto foi desenvolvido como atividade prática de Engenharia de Prompt utilizando Inteligência Artificial generativa. O objetivo era aprimorar prompts em até 5 tentativas para gerar uma imagem medieval cinematográfica com alta qualidade visual e texto legível.

Durante o processo, foram aplicadas técnicas de refinamento de prompts, análise crítica das respostas da IA e ajustes progressivos para melhorar detalhes visuais, composição artística e legibilidade da imagem.

🎯 Objetivo da Atividade
Aprender técnicas de Engenharia de Prompt;
Refinar instruções para modelos de IA;
Melhorar resultados visuais através de iterações;
Analisar como pequenas mudanças nos prompts impactam a geração final.
🖼️ Resultado Final

A versão final apresentou:

Estilo medieval/barroco cinematográfico;
Elementos náuticos e reais detalhados;
Texto mais legível;
Melhor iluminação e composição visual;
Aparência mais profissional e artística.
🛠️ Ferramentas Utilizadas
Qwen AI
Engenharia de Prompt
Inteligência Artificial Generativa
📚 Aprendizados

Este projeto demonstrou como a clareza e o refinamento progressivo de prompts influenciam diretamente na qualidade dos resultados gerados por IA.
