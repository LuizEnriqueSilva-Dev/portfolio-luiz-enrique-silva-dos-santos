# SM2 - Laboratório de Classificação Visual

## 📖 Sobre
Projeto desenvolvido para analisar o funcionamento de modelos de classificação visual utilizando Inteligência Artificial. O trabalho explora reconhecimento de expressões faciais, limitações da IA e possíveis impactos sociais causados por erros de interpretação emocional.

## 🎯 Objetivo
- Explorar conceitos de classificação visual;
- Analisar reconhecimento facial por IA;
- Identificar limitações do modelo;
- Discutir impactos sociais da tecnologia.

## 🛠️ Ferramentas Utilizadas
- Teachable Machine
- Inteligência Artificial
- Classificação Visual

## 🖼️ Resultado
O projeto demonstrou como erros na seleção de dados podem afetar a interpretação das emoções, além da importância da validação humana para melhorar a precisão do modelo.
